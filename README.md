# Firestore Todo App

A Flutter to-do list app that stores tasks in **Cloud Firestore** and updates in real time.
Built for the African Leadership University Week 8 QA Session.

## Features

- **Create** – add a new todo
- **Read** – see all todos live, newest first (real-time stream)
- **Update** – tick a todo as completed, or edit its text
- **Delete** – remove a single todo
- **Bonus** – clear all completed todos at once using a batch delete

## Tech Stack

- Flutter (Dart)
- Firebase Core
- Cloud Firestore

## Project Structure

```
lib/
  main.dart              # App entry point, initialises Firebase
  todo_screen.dart       # UI: input field, list, edit dialog
  todo_service.dart      # Firestore CRUD functions
  firebase_options.dart  # Generated by FlutterFire CLI
```

## How It Works

| Action | Firestore method |
| --- | --- |
| Add todo | `collection('todos').add({...})` |
| Show todos live | `.orderBy('timestamp', descending: true).snapshots()` |
| Toggle complete | `.doc(id).update({'completed': !currentStatus})` |
| Edit todo | `.doc(id).update({'task': newTask})` |
| Delete todo | `.doc(id).delete()` |
| Clear completed | `where('completed', isEqualTo: true)` + `batch.delete()` |

Each todo document looks like this:

```json
{
  "task": "Finish assignment",
  "completed": false,
  "timestamp": "server time",
  "updatedAt": "server time"
}
```

## Getting Started

1. Clone the repo:
   ```
   git clone https://github.com/YOUR-USERNAME/todo_app.git
   cd todo_app
   ```
2. Install packages:
   ```
   flutter pub get
   ```
3. Connect your own Firebase project (optional):
   ```
   flutterfire configure
   ```
4. Run the app:
   ```
   flutter run -d chrome
   ```
